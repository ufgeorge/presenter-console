# Presenter Console 使用手冊

把手機變成簡報講者的中控台：換頁、開始簡報、同步顯示講者備註、語音備註播報、觀眾提問 — 全部透過手機瀏覽器完成，手機不用裝任何 App。

版本：v0.9.5 · 適用 Agent 標題 `Presenter Console Agent v0.9.5`

---

## 1. 系統需求

| 項目 | 需求 |
|---|---|
| 電腦 | Windows 10 / 11（64 位元） |
| PowerPoint | 要控制 PowerPoint 時需安裝（Desktop 版，含講者備註） |
| Open Design | 要控制 Open Design 簡報時需安裝 |
| 手機 | iPhone（iOS 16.4+ Safari）或 Android（Chrome） |
| 網路 | 手機與電腦連**同一個 WiFi**（或手機開熱點讓電腦連） |

> 電腦不需要安裝 .NET、不需要安裝任何開發工具。

---

## 2. 安裝

1. 到 GitHub Releases 下載 `presenter-console-<版本>-win-x64.zip`
2. 解壓到**任意資料夾**（建議放桌面或文件）
3. 執行資料夾內的 `PresenterConsole.Desktop.exe`

**Windows SmartScreen 警告**（第一次執行會出現「Windows 已保護您的電腦」）：

> 這是因為發布檔沒有付費數位簽章，屬正常現象。
> 按「**更多資訊**」→「**仍要執行**」。

**Windows 防火牆詢問**（第一次執行可能出現）：

> 勾選「**私人網路**」→「允許存取」。
> 不允許的話手機將無法連上電腦。

---

## 3. 連線準備

**方式 A：同一 WiFi（推薦）**
手機與電腦連同一個 WiFi 基地台。

**方式 B：手機熱點（現場沒有網路時）**
1. 手機開「個人熱點」
2. 電腦斷開原本 WiFi，連上手機的熱點
3. 重新啟動 Agent（IP 會變，QR Code 也會更新）

> ⚠️ 開熱點的那支手機無法同時當控制端，需要第二支手機/平板控制。

---

## 4. 快速開始（PowerPoint 範例）

1. 電腦用 PowerPoint 開啟你的簡報
2. 執行 `PresenterConsole.Desktop.exe`，Agent 視窗出現 **QR Code**
3. 手機相機掃描 QR Code → 自動開啟控制頁
4. 手機狀態列顯示「已連線」
5. 在電腦上按 **F5** 開始放映（或直接用手機按「▶ 開始簡報」）
6. 開始用手機換頁、看備註

---

## 5. 手機控制介面說明

```
┌─────────────────────────────┐
│ ● 已連線     3 / 42   📁 💬 │  ← 狀態列：連線、頁碼、面板開關
│ [ 簡報挑選 ▾ ]              │  ← 多簡報時下拉切換
│                             │
│  講者備註內容…               │  ← Notes 區（可調字級/字色）
│                             │
│ ▶ 開始簡報   ↩ 回簡報        │
│       ◀ PREV   NEXT ▶       │
└─────────────────────────────┘
```

| 按鈕 / 元素 | 功能 |
|---|---|
| 狀態列 | 連線狀態、目前頁碼 / 總頁數 |
| 📁 icon | 展開 / 收合「簡報挑選」面板 |
| 💬 icon | 展開 / 收合「觀眾提問」面板 |
| 簡報挑選 | 同時開多個簡報時，下拉選擇要控制哪一個 |
| Notes 區 | 目前頁的講者備註；可用 A− / A+ 調整字級，色票換字色（會記住） |
| ▶ 開始簡報 | 從第一頁開始放映（PowerPoint） |
| 從目前頁開始 | 從目前頁開始放映（PowerPoint） |
| ↩ 回簡報 | 任何狀態下一鍵回到簡報視窗 |
| ◀ PREV / NEXT ▶ | 上一頁 / 下一頁（大按鈕，實體機好按） |

> 手機顯示的頁碼永遠以電腦實際狀態為準，不會自己跳。

## 6. 支援的簡報來源

### PowerPoint
- 手機可：開始簡報、從目前頁開始、換頁、看備註、回簡報
- 電腦端用鍵盤 / 滑鼠 / 簡報筆換頁時，手機頁碼會同步更新
- 同時開多個簡報檔 → 手機下拉切換

### Open Design
- 在 Open Design 中**手動開始播放**（全螢幕）後，手機負責：換頁（方向鍵）、講稿顯示
- 多個專案 → 手機下拉切換
- 講稿來源：專案內的講者備註（新版格式自動讀取）

## 7. 語音備註（可選）

在 PowerPoint 講者備註（或 Open Design 講稿）中寫入指令，手機就會**自動朗讀**：

| 語法 | 效果 |
|---|---|
| `[voice]歡迎大家` | 手機朗讀「歡迎大家」（講稿中不顯示此行文字） |
| `[2 sec]` | 停頓 2 秒（獨立一行或接在語音後） |
| `[voice]第一段 [5 sec] [voice]第二段` | 唸第一段 → 停 5 秒 → 唸第二段 |

- 唸完換頁即停止；同一頁回到時不會重播
- 適合講者戴耳機聽提示，不打擾觀眾
- ⚠️ 手機需有中文語音：iPhone 內建；Android 若未安裝中文語音包，手機會顯示提示

---

## 8. 觀眾提問（可選）

1. 放映中，手機按「💬」展開面板 → 「顯示提問 QR」
2. 電腦會跳出全螢幕 QR Code 畫面（蓋在簡報上）
3. 觀眾用手機相機掃碼 → 開啟提問頁 → 輸入問題送出（免登入、限 200 字、同 IP 10 秒一則）
4. 你的控制手機即時顯示觀眾問題 → 可以刪除
5. 按「↩ 回簡報」關閉 QR 畫面回到簡報

---

## 9. 螢幕不休眠

- 控制頁會自動嘗試保持手機螢幕亮著（Wake Lock / NoSleep）
- 若顯示「⚠ Wake Lock 不可用」，點一下「重新啟用」即可
- 極少數手機仍需手動關閉自動鎖定：
  - iPhone：設定 → 螢幕顯示與亮度 → 自動鎖定 → 永不（用完記得改回）
  - Android：設定 → 顯示 → 螢幕逾時 → 永不

## 10. 常見問題（FAQ）

**Q1. 手機打不開控制頁 / 一直「連線中…」**
- 確認手機與電腦在同一 WiFi（或熱點）
- 確認執行 Agent 時防火牆有允許「私人網路」
- 關掉手機瀏覽器分頁，重新掃 QR Code

**Q2. 手機連上了，但按按鈕沒反應**
- 先確認簡報真的在放映中（PPT 按過 F5 / Open Design 已手動播放）
- 重新整理手機頁面再試

**Q3. 按「開始簡報」沒反應**
- 確認 PowerPoint 視窗**沒有縮到最小**（縮到工作列）
- 若電腦有安全軟體鎖住視窗切換，手動在電腦點一下 PowerPoint 再按 F5

**Q4. 語音沒聲音**
- iPhone：先點一下手機螢幕（瀏覽器需要一次互動才允許發聲）
- Android：手機會提示「未安裝中文語音」→ 到手機設定安裝中文語音包
- 確認備註語法正確（`[voice]` 指令）

**Q5. 怎麼確認自己用的是不是最新版？**
- 電腦端：看 Agent 視窗標題 `Presenter Console Agent vX.Y.Z`
- 手機端：控制頁最下方「手機版本 vN」（這是手機介面版本，不是 Agent 版本）
- 版本對不上 → 重新下載最新 zip

**Q6. 控制頁顯示的簡報選不到 Open Design？**
- 先啟動 Open Design，再在 Agent 視窗的「簡報軟體」下拉選 Open Design 並按「套用」
- 若提示「請先設定 OpenDesign 資料夾」→ 按「設定資料夾」選擇你的專案資料夾
- 播放請在 Open Design 中手動開始

**Q7. 手機頁碼跟電腦不同步**
- 按「↩ 回簡報」或重新整理手機頁面，會自動重新同步

## 11. 隱私說明

- 不上傳任何資料、無帳號系統、無雲端伺服器
